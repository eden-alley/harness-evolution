## 问题、解决方法与效果

| 问题 | 本项目采用的方法与来源 | 实测效果和剩余问题 |
| --- | --- | --- |
| 1. 文件引用的行号会忽略物理空行 | 沿用 v0.41 的 `read_file` 修复。对照冻结源文件逐行核对工具返回的行号，再检查真实报告引用。[原修复](https://github.com/eden-alley/harness-evolution/commit/8a4aa743cecc81848ba045cc09e6720a651b6c79) | 同一批历史读取重放，准确记录从 1/11 提高到 11/11。全量中 C01 的四组源码定位及因果解释通过，O02 的引用和版本解释通过。U02 仍有代码行为解释错误。 |
| 2. Shell 在错误目录启动命令，失败后重复探查 | 根据本项目命令轨迹，在工具说明中写明工作目录、相对脚本路径和绝对解释器路径的用途。识别 Git Bash/MSYS 初始化错误时，保留原始错误并提示可选的 cmd 等价命令。[命令工具](../../tools.py) | 两组专项的准备错误分别从 6 次和 2 次降至 0 次。全量采用独立 Sandboxie 测试箱，Git Bash 管道、注册表模拟凭证隔离、文件交接等 14 项检查通过。另有 5 题共 8 次常见列目录命令被拒；同一文件用内置 `list_dir` 可见。默认 MXC 后端仍有 Git Bash 启动和注册表模拟凭证隔离两项已知失败。 |
| 3. 模型可能改写要求保留的文件 | 调用方通过 `AGENT_READ_ONLY_PATHS` 指定工作区一级文件或目录。内置文件工具在写入前检查，原生 Shell 执行同一组只读规则，检查点绑定该策略。方法参考执行前拦截。[Claude Code PreToolUse](https://code.claude.com/docs/en/hooks#pretooluse) · [本项目权限实现](../../permissions.py) | 专项验证了受保护原件字节保持一致，其他位置仍可写。全量 O09 首次覆盖被拒，模型随后正确另存。范围检查从 17/20 提高到 18/20；U05 改了已有测试，C04 多交付了题面范围外的测试文件。 |
| 4. 模型在报告或产物有错时仍会结束任务 | 复用现有收尾验收入口。调用方用 `/check` 绑定下一任务的检查命令；提交时执行，失败后将输出交给模型修正一次，再运行同一检查。使用模型验收报告时，经原有权限重读落盘正文。[Claude Code Stop](https://code.claude.com/docs/en/hooks#stop) · [本项目验收入口](../../verification.py) | 两份已知错误的原报告从实际提交点回放，关闭检查时修正 0/2，开启时修正 2/2。全量 O06 经反馈修正并复验通过。U01、U02 的功能测试都通过，报告中仍有事实错误；公开测试没有覆盖这些解释。 |
| 5. 压缩可能打乱指令顺序，中断后有重复写入风险 | 压缩时按原顺序保留用户原文和近期完整工具批次，丢弃含模拟对话标记的摘要。已绑定检查的任务恢复时核对命令摘要，沿用已记录的工具结果。参考 Codex 的压缩处理和 LangGraph 的恢复边界。[Codex 压缩实现](https://github.com/openai/codex/blob/main/codex-rs/core/src/compact.rs) · [LangGraph 检查点与恢复](https://docs.langchain.com/oss/javascript/langgraph/thinking-in-graph-api) | 受控样本从 27 条消息缩至 11 条，估算 token 从 6,114 降至 2,748，交付金额 76.10。全量 O08 在新进程续跑，回执只写一次，交付 116.00。O07 第五轮摘要达到 4,096 输出 token 上限，未交付最终文件。 |

## 运行与复核

本批由平台外的 Sandboxie 测试箱执行，随后将原件导入代理评估实验室。主批启动 20 题，19 题形成判分。C04 主批发出 11 次请求后宿主中断，另行补测 18 次；补测的功能、冲突处理和报告通过，范围检查失败。两份轨迹分别归档，整题计一次。

模型为 `deepseek-v4.1-flash-1017`。365 次请求中有 364 份用量回执，按冻结费率估价 ¥10.544670；第 247 次另预留 ¥0.121944。补录与生成对比报告的模型费用为 ¥0。两版各一次运行，工具环境和部分提交前检查有差别，表中的变化只描述这批样本。

在本地代理评估实验室可按运行 ID `harness-ext20-sbie-20261120` 查找原件，对比报告 ID 为 `102db014-e825-4b0e-b730-56759f418f40`。后续全量评测统一使用实验室的 `scripts/evaluation.py` 冻结并启动，完成对比后取得报告回执。

提交前在 Windows 宿主通过 `python tests/run_offline.py` 重新运行基础回归，298 项通过。Windows 默认后端的原生边界验收入口为 `python tests/run_offline.py --native`。Sandboxie 的 14 项检查属于本批独立评测环境。
